# AI 诗人 · 看图作诗实验室

课程作业项目，对应 Lecture V9 第 30 讲「人工智能诗人 · 语言生成」。

## 项目做了什么

课件的核心问题是：**押韵容易，写出意味难。** 诗歌既有字数、韵脚、平仄等可检验的形式，也有连贯意象与情感；满足前者并不自动得到好诗。

本项目把「看图作诗」拆成可观察、可评价的几个环节：

1. **看图**：上传图片后，在浏览器本地采样像素主色调，推断场景（春景 / 秋夜 / 山水 / 雪景 / 夜雨），并给出对象、场景与氛围关键词。
2. **作诗**：以七言绝句（4 句 28 字）为例，按「2+2+3」句式拼接初稿。
3. **生成后再修改（BIPro 思路，ACL 2025）**：不是一次写完就交卷，而是先修形式（统一第 1、2、4 句韵脚），再修表达（替换重复、通用的用词）。页面完整展示三轮稿件。
4. **形式与表达分开评估**：
   - 形式：逐项核对句数、每句字数、第 2/4 句押韵；
   - 内容：主题贴合、意象连贯、套用风险、整体意境——只给提示，不给「统一分数」。
5. **盲评**：隐去作者，把机器生成诗与经典诗作匿名并排比较；读者选择并记录理由，避免只统计「喜欢率」。投票记录保存在浏览器本地。
6. **知识卡片**：古代诗词分类、方法演进时间线（拼贴 → 统计 → 神经模型 → BIPro → Honglou-Poem）、关键思路与待解决问题。

## 技术说明

- 纯静态站点：HTML + CSS + 原生 JavaScript，没有任何后端或第三方 API 依赖。
- 图片分析在浏览器内用 Canvas 完成，图片不会上传到服务器。
- 生成引擎基于词库、句式模板与可复现的伪随机数，用于**演示方法流程**，不代表真实大模型的诗歌生成能力。
- 可直接托管在 GitHub Pages。

## 本地运行

直接双击 `index.html` 即可打开。若浏览器限制本地文件读取，可在项目目录启动一个静态服务器：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署到 GitHub Pages（交作业网址）

1. 在 GitHub 新建仓库，名称填 `ai-poet-lab`，设为 Public。
2. 把本项目所有文件上传到该仓库根目录（必须包含 `index.html`）。
3. 进入仓库 **Settings → Pages**。
4. **Build and deployment** 中，Source 选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/ (root)`，点击 Save。
6. 等待 1–2 分钟，页面顶部会出现访问地址：

```
https://<你的GitHub用户名>.github.io/ai-poet-lab/
```

这个网址就是可以提交给老师的作业网址。

## 与课件的对应关系

| 课件要点 | 项目对应位置 |
| --- | --- |
| 看图作诗要提取对象、场景、氛围 | 「看图作诗」的图片上传与意象提取 |
| 七言绝句四句 28 字、押韵与节奏 | 生成引擎与形式检查 |
| 从拼贴到条件生成 | 知识卡片的时间线 |
| BIPro：生成后再修改 | 三轮稿件对比 |
| 形式与表达分开检查 | 「双轨评估」 |
| 盲评、避免只报喜欢率 | 「盲评」模块 |
| 没有能替代文学判断的统一分数 | 内容检查只给提示不给分 |
